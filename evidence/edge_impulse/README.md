# Edge Impulse records

Screenshots supplied on 4 Nov 2026, renamed by the visible content for easier review. The validation and test screenshots show different experiments, model versions, and data splits; their percentages should not be compared as one final score.

The supplied ZIP contains screenshots and a sensor-storage photo only. It does not contain raw accelerometer/gyroscope recordings for importing. The public Edge Impulse project `DAIMIAN / MAGIC2` (ID 1153638) already displays a dataset with six labels sampled at 50 Hz. To add new recordings, use the raw Edge Impulse export/CSV or JSON data files in an editable project; the public view offers cloning rather than direct editing.
